# 📊 FLEXISAF: Python, Data Analysis & Visualization Projects

Welcome to the **FLEXISAF** project repository! This repo contains a series of modular learning projects focused on Python programming, data analysis, and visualization. The goal? To build end-to-end data skills by applying real-world datasets and use cases across three structured modules.

## 🧠 Modules Breakdown

### 📦 Module 1: Python Programming + Intro to Visualization
This module dives into basic Python scripting and an early look at Matplotlib for visualization.

- `Rock, Paper, Scissors.py`: A CLI game written in Python.
- `Tic-Tac-Toe.py`: Another classic game to practice conditionals and loops.
- `Data Visualization.ipynb`: Uses **company_sales_data.csv** to generate bar charts and line plots with **Matplotlib**.

> 🧰 Tools: Python, Jupyter Notebooks, Matplotlib

---

### 📈 Module 2: Exploratory Data Analysis (EDA)
In this module, we begin exploring data professionally with Pandas and visualization techniques.

- `Module 2 pt1&2.ipynb`: A deep dive into **SampleSuperstore.csv**, exploring sales trends, regions, product categories, and key KPIs.
- Clean visual storytelling and EDA principles applied using **Seaborn** and **Matplotlib**.

> 🧰 Tools: Pandas, Seaborn, Matplotlib, Python

---

### 📊 Module 3: Visualization Mastery
Focused entirely on building insightful and appealing data visualizations.

- `Visualization.ipynb`: A continuation of the Superstore dataset with advanced plots, dashboards, and storytelling techniques.
- Emphasis on customizing plots, color theory, and drawing business insights from visuals.

> 🧰 Tools: Python, Matplotlib, Seaborn

---

## 📂 Datasets Used

- `company_sales_data.csv`: Sales data used in Module 1 for charting practice.
- `SampleSuperstore.csv`: A popular dataset used for analysis and visualization in Modules 2 & 3.

## 📌 How to Run

1. Clone this repo:
   ```bash
   git clone https://github.com/your-username/FLEXISAF.git
   cd FLEXISAF
   ```

2. Create a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate  
   On Windows: venv\Scripts\activate
   ```

3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

4. Open the Jupyter Notebooks:
   ```bash
   jupyter notebook
   ```
